# Brain · 2. Healthy: vascular

*Part of the [brain module](../README.md). Status: dataset selected, no model trained, no data downloaded.*

**What it teaches.** Traces and names the arteries of the circle of Willis on TOF-MRA and CTA, including their common variants.

**Dataset.** **TopCoW** (12 named artery segments, 125 paired CTA and MRA cases), with the CC0 Lausanne cohort's healthy controls as a companion. Full reasons, alternatives and access terms: [DATASETS.md](../DATASETS.md).

**Weights ceiling.** Non-commercial unless the TopCoW data owner permits.

**Stated limit.** No permissively licensed dataset with named-artery labels is in the catalogue today.

For learning anatomy and pathology from labelled public cases, never to say what a
person has. `DATA.md`, `MODEL_CARD.md` and the notebook arrive when this use is built.
