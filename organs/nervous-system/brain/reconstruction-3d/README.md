# Brain · 5. 3D reconstruction

*Part of the [brain module](../README.md). Status: dataset selected, no model trained, no data downloaded.*

**What it teaches.** Rebuilds, in 3D, the structures and lesions segmented by uses 1 to 4, and places them in a healthy reference space for comparison.

**Dataset.** **MNI ICBM152 2009** (population-average healthy template) and the **Open Anatomy SPL/NAC brain atlas** (300+ labelled structures with 3D models), with the HRA brain meshes as a companion. Full reasons, alternatives and access terms: [DATASETS.md](../DATASETS.md).

**Weights ceiling.** Permissive (copyright notice, attribution and marked changes as each source requires).

**Stated limit.** This use comes after the 2D models; it trains nothing new on its own.

For learning anatomy and pathology from labelled public cases, never to say what a
person has. `DATA.md`, `MODEL_CARD.md` and the notebook arrive when this use is built.
